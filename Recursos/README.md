# Recursos

Esta carpeta contiene los materiales compartidos por la documentación del repositorio.

## Imágenes

- `Imágenes/equipo.jpg`: fotografía grupal usada en el README principal.
- `Imágenes/Integrantes/`: retratos cuadrados optimizados para la tabla de integrantes.
- `Imágenes/Integrantes/Originales/`: fotografías originales, conservadas para futuras ediciones.
- `Imágenes/ODS/`: insignias de los ODS seleccionados por el equipo.

Usar nombres breves, descriptivos y sin datos temporales de la cámara. Antes de agregar una imagen nueva, comprobar que el equipo tenga permiso para publicarla.

## Archivos

- [`Archivos/Taller_04_LE.xlsx`](Archivos/Taller_04_LE.xlsx): lista de exigencias del proyecto.
- [`Archivos/Taller_05_Mediciones.xlsx`](Archivos/Taller_05_Mediciones.xlsx): registro de mediciones y cálculo de errores.
