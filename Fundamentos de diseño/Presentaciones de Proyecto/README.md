# Presentaciones del proyecto

Esta carpeta reúne el material utilizado para comunicar los avances y resultados del proyecto.

Cuando corresponda, guardar aquí:

- presentaciones editables (`.pptx`);
- versiones exportadas a PDF;
- póster final en PDF;
- recursos propios de la exposición que no pertenezcan a otro módulo.

Usar nombres como `Avance_01.pdf`, `Presentacion_final.pptx` y `Poster_final.pdf`. No crear archivos vacíos como marcadores.
